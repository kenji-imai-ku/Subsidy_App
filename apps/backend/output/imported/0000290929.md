令和8年度浄化槽補助金の交付申請について
--------------------

京都市では、公共下水道認可区域外等にお住まいの方々の健康で快適な生活を確保するとともに、河川の水環境保全のため、トイレの排水だけでなく、台所や風呂、洗たく等の生活雑排水を併せて処理できる浄化槽（合併処理浄化槽）の設置を推進しています。

　詳しくは、[環境保全創造課](https://www.city.kyoto.lg.jp/kankyo/page/0000128044.html)までお問合せください。

### 1　補助対象

京都市内にお住まいで、次の項目に該当される方が補助の対象となります。

**該当の可否については、環境保全創造課までお問合せください**。

（1）　対象となる区域

　　下水道事業計画区域以外の区域

（2）　対象となる建物

　　自らがお住まいになる専用住宅等

　　（事務所等を兼ねる建物は、その住宅部分）

　　※例：事務所、日用品販売店、学習塾、飲食店等

（3）　対象となる方

　　ア　既存単独処理浄化槽に換えて浄化槽を設置する個人

　　イ　くみ取り便槽に換えて浄化槽を設置する個人

　　ウ　専用住宅等を新築・増築し、浄化槽を設置する個人（条件あり）

### 2　補助額

（1）浄化槽設置に係る補助金額

人槽毎の補助額（円）

|  |  |
| --- | --- |
| 人槽 | 補助額 |
| 5 | 332,000 |
| 6～7 | 414,000 |
| 8～10 | 548,000 |
| 11～20 | 939,000 |
| 21～30 | 1,472,000 |

浄化槽設置に係る補助金額は、浄化槽の整備に要する経費のうち、浄化槽本体費用、本体の設置に必要な工事費（流入、放流に係る管きょ及びますに係る費用を除く。）と人槽毎の補助額のいずれか少ない額です。

（2）　宅内配管に係る補助金額（既存単独処理浄化槽に換えて浄化槽を設置する方のみ）

　　宅内配管補助対象経費の総額又は33万円のいずれか少ない額です。

### 3　申請方法

（1）　申請期間

　　　令和8年度の受付期間は、**4月1日（水曜日）から12月28日（月曜日）まで**です。

　　※助成金額が予算額に達した場合は、期間中であっても申請受付を終了する場合があります。

　　※**補助対象の浄化槽の****設置工事の開始の日の7日前までに、補助金交付の申請を行う必要があります**。

　　　また、工事完了後速やかに又は**令和9年3月20日までに工事完了届出を行う必要があります**。

　　　詳しくは、「浄化槽補助金申請及び交付手続きの流れ」をご確認ください。

（2）　申請に必要な書類

　　　浄化槽補助金交付申請書に、必要書類（「浄化槽補助金申請及び交付手続きの流れ」をご確認ください）を添えてください。

（3）　申請先

　　　京都市環境政策局環境企画部環境保全創造課（旧 環境指導課）

　　　京都市中京区寺町通御池上る上本能寺前町488番地　京都市役所本庁舎1階

（4）　 申請書

　　ア　[こちら](https://www.city.kyoto.lg.jp/kankyo/page/0000034726.html)からダウンロードできます。

　　イ　京都市環境政策局環境企画部環境保全創造課でも配布しています。
