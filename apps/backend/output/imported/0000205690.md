入院助産制度
======

ページ番号205690

2025年10月7日

入院助産制度とは
--------

入院助産制度とは、保健上必要があるにもかかわらず、経済的理由により、入院助産を受けることができない妊産婦に対し、児童福祉法第22条に基づき、助産施設（下記「市内の助産施設一覧」参照）において助産を行うことで、安全で衛生的な出産を保障する制度です。

対象者
---

1. 生活保護を受けている世帯
2. 当該年度分(4月〜6月出産の方は前年度分)の市民税が非課税の世帯
3. 当該年度分(4月〜6月出産の方は前年度分)の市民税の均等割のみ課税の世帯
4. 当該年度分(4月〜6月出産の方は前年度分)の市民税の所得割の額が19,000円以下で、市長が特に必要と認めた世帯

ただし、3、4については、健康保険(国民健康保険を含む)から給付を受けることができる額(出産育児一時金)が488,000円（産科医療補償制度により加算される額（12,000円）を除いた額）以上の方は、利用できません。

利用料金（本人負担額）
-----------

利用料金（本人負担額）表

| 区分 | 基本額（円） | 加算額（円） |
| --- | --- | --- |
| 対象者1に該当する方 | 0 | 0 |
| 対象者2に該当する方 | 2,200 | A×0.2  （加算額：97,600） |
| 対象者3に該当する方 | 4,500 | A×0.3  （加算額：146,400） |
| 対象者4に該当する方 | 【所得割の額9,000円以下】6,600  【所得割の額19,000円以下】9,000 | A×0.5  （加算額：244,000） |

※Aは、出産育児一時金から、産科医療補償制度により加算される額（1.2万円）を除いた額を表します。

* 対象者2のうち、単身世帯やひとり親世帯、障害者世帯などに該当する方については、基本額が免除され、利用料金は97,600円になります。
* 多胎出産の場合、「基本額」＋「加算額×出生児数」が利用料金となります。
* この金額は出産のために入院されてから退院されるまで、入院助産を受ける費用で、入院前・退院後の費用や交通費は含みません。また、この他に病院によりおむつ代などの実費を請求される場合があります。
* 利用料金は、退院日以降に京都市により納付書を送付しますので、お近くの金融機関で納付してください。
* なお、京都市国民健康保険の被保険者の方は、納付書の代わりに、国民健康保険から受け取る出産育児一時金から利用料金を差し引いて直接納付することができます。詳しくは区役所・支所の保健福祉センター子どもはぐくみ室（子育て推進担当）でお尋ねください。

手続き
---

助産施設を利用される方は、世帯の課税状況を把握したうえで、お住まいの区の区役所(支所)の[保健福祉センター子どもはぐくみ室(子育て推進担当)](https://www.city.kyoto.lg.jp/hokenfukushi/page/0000134951.html)へ、次の書類を添えて事前にお申し込みください。

1. 児童福祉施設入所申込書(用紙は区役所(支所)の[保健福祉センター子どもはぐくみ室(子育て推進担当)](https://www.city.kyoto.lg.jp/hokenfukushi/page/0000134951.html)にあります。)
2. 健康保険の資格情報がわかるもの（マイナポータルの資格情報画面、「資格情報のお知らせ」、資格確認書、健康保険被保険者証（令和7年12月1日までに限る）など）
3. 助産施設で出産を予約している証明書(入院予約票など)
4. 出産予定日を証明する書類(母子健康手帳(写)など)
5. 個人番号確認書類及び本人確認書類
6. 障害者世帯については障害者手帳等の写し（対象者2の方のうち、基本額が免除となる障害者世帯のみ）

入所の決定
-----

区役所(支所)の[保健福祉センター子どもはぐくみ室(子育て推進担当)](https://www.city.kyoto.lg.jp/hokenfukushi/page/0000134951.html)で必要な審査を行ったうえ入所を決定します。

なお、入所承諾後に世帯状況の変更、住所変更、健康保険への加入・脱退、多胎出産、出産予定病院の変更等により、申込み内容に変更が生じた場合には決定の変更が行われる場合がありますのでお申し出ください。また、入所が適当と認められなくなった場合は、承諾を解除します。
