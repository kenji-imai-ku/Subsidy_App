# 京都市支援制度データ収集パイプライン 仕様書 (scraper_pipeline.py)

## 1. システム概要
本システムは、京都市公式ウェブサイトから「給付金・助成金・支援金・補助金」に関する情報を自動的に収集し、構造化されたデータとして出力するETL（Extract/Transform/Load）パイプラインです。

### 全体フロー
1.  **Extract (収集)**: DuckDuckGoおよびTavily Search APIを併用し、京都市HP内の対象ページURLを網羅的に取得。
2.  **Transform (判定・変換)**: 取得したページの概要をOpenAI API (GPT-4o) で判定し、支援制度に関連するページのみをMarkdown形式に変換。
3.  **Load (出力)**: 最終的なMarkdownファイルを output ディレクトリに保存。

---

## 2. アーキテクチャと技術選定の変遷

本プロジェクトでは、検索エンジンのAPI制限や環境の変化に柔軟に対応するため、以下の変遷を経て現在の「二刀流（ハイブリッド）」構成に至りました。

### 初期構想: Google Custom Search API
当初は信頼性の高い Google Custom Search API を検討していましたが、**2026年1月をもって新規受付を停止するGoogleのポリシー変更**により、403 Forbiddenエラーを回避できないことが判明しました。

### 現在の構成: プランB「二刀流（ハイブリッド検索）」
APIの可用性リスクを分散し、かつ検索エンジンごとの得意分野（クローラ速度やインデックスの深さ）を補完し合うため、以下の2つを併用する構成を採用しました。

-   **DuckDuckGo (ddgs)**: ライブラリベースでAPIキー不要。迅速な検索が可能。
-   **Tavily Search API (tavily-python)**: AIエージェント向けに最適化された検索エンジン。精度の高いURL抽出が可能。

この構成により、一方が制限やエラーに見舞われても、もう一方が補完することでシステムの稼働（網羅性と堅牢性）を担保しています。

## 3. 主要機能の詳細仕様

### 3.1. 複数クエリ検索 & 重複排除
網羅性を極限まで高めるため、以下の4つの検索クエリを独立して実行します。
- site:www.city.kyoto.lg.jp 給付金
- site:www.city.kyoto.lg.jp 助成金
- site:www.city.kyoto.lg.jp 支援金
- site:www.city.kyoto.lg.jp 補助金

各エンジンから最大50件（計400件以上の候補）を抽出し、 list(set(all_urls)) によって重複を完全に排除したクリーンなリストに対してスクレイピングを実行します。

### 3.2. ローカルキャッシュ機構
開発効率の向上と無駄なAPI消費を抑えるため、 search_cache.json によるキャッシュ機構を搭載しています。
- キャッシュが存在する場合：外部検索を実行せず、前回のURLリストを再利用。
- キャッシュが存在しない場合：新規に検索を実行し、結果をファイルへ保存。

### 3.3. OpenAI判定のチューニング（網羅性優先）
判定フェーズでは、**「取りこぼし（False Negative）をゼロにする」**という方針でプロンプトをチューニングしています。
- **寛容な判定基準**: 受付期間が終了している可能性があるページや、対象者が非常に限定的な制度であっても、制度の概要を説明していれば is_target: true として抽出します。
- **ノイズ除去**: 議事録、入札情報、アクセス案内など、明らかに制度説明ではないもののみを除外対象とします。
- **判定理由の記録**: OpenAIが is_target: false と判断した場合は、その理由（例：単なるニュースリリースであるため）がコンソールに出力されます。

## 4. 環境準備・依存関係

### 必要ライブラリ
```bash
poetry add requests beautifulsoup4 markdownify openai python-dotenv duckduckgo-search tavily-python
```

### 環境変数 (.env)
プロジェクトのルートにある .env ファイルに以下のキーを設定してください。
```env
OPENAI_API_KEY=sk-...
TAVILY_API_KEY=tvly-...
```
※ プログラム起動時にこれらの環境変数が存在するかバリデーションが行われ、不足している場合は実行が停止されます。

---

## 5. 運用の手引き

### 基本的な実行
```bash
poetry run python scraper_pipeline.py
```

### 最新データの再取得
検索結果を更新し、最新のページリストを取得したい場合は、キャッシュファイルを削除してから実行してください。
```bash
rm search_cache.json && poetry run python scraper_pipeline.py
```

### トラブルシューティング
- **Timeouts**: スクレイピング対象サイトへの負荷を考慮し、リクエスト間に time.sleep(1) を挟んでいます。タイムアウトが頻発する場合はこの値を調整してください。
- **API Limits**: TavilyやOpenAIの無料枠上限に達した場合は、それぞれの管理画面でクォータを確認してください。
